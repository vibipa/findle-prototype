Findle prototype: GitHub Pages steps

1. Create a free GitHub account and a new public repository named findle-prototype.
2. In the repository, choose Add file > Upload files and upload everything in this folder (keep the deals and images folders).
3. Settings > Pages > Source: Deploy from a branch > main > / (root) > Save.
4. Your site address will be https://YOUR-vibipa.github.io/findle-prototype/
5. Before uploading, replace https://vibipa.github.io/findle-prototype in ALL files with your real address
   (Notepad: Edit > Replace; Mac TextEdit: use find and replace in each file; or run: sh set-url.sh YOUR-USERNAME).
6. Test: open https://search.google.com/test/rich-results and enter your home page and each deal page.
7. Search Console: add your site as a URL-prefix property, verify, and submit sitemap.xml.
8. Wait a few days, then search for your deals and see what Google shows.
